# 登录页 Alex Friends IP 融合设计

## 目标

保留并强化左侧卡通人物为 **Alex Friends** 品牌 IP，解决文案层与人物层「断层」问题，提升场景融合度与专业完成度。

## Phase 1 范围（已实现）

- 左侧改为 `login-visual-panel` 纵向一体化布局
- 标题 **Meet Alex Friends**，避免与页顶 Alex Platform 重复
- 能力列表与四角色一一映射（Mini/Aleo/Nova/Sunny）
- 温暖 slogan：**让管理更简单**
- 人物舞台：蓝色光晕 + 椭圆地面阴影 + 品牌蓝描边/光晕
- 人物尺寸放大约 20%（宽 145px）
- 入场上浮动画 + `prefers-reduced-motion` 降级
- 眨眼间隔调整为 8–12 秒
- IP 常量抽离至 `src/views/login/config/alexFriends.ts`

## Phase 2（体型差异化、3D 软胶质感与微交互升级）

- **高矮胖瘦体型差异化**：彻底打破四柱等宽柱状图既视感
  - **Mini（珊瑚红）**：矮胖敦实团子（`84px × 146px`，宽圆角 `44px 44px 20px 20px`），宽眼距、粉腮红、微笑弧线，代表亲和贴心的用户管理。
  - **Aleo（罗兰紫）**：高瘦挺拔修长（`50px × 292px`，紧凑圆角），半透明细框眼镜（Glasses）、冷静抿嘴，代表缜密的数据分析。
  - **Nova（晴空蓝）**：匀称干练中坚（`64px × 224px`），灵动呆毛（Tuft）、开心笑口，代表敏捷高效的工作流引擎。
  - **Sunny（暖阳黄）**：微胖圆润小胶囊（`76px × 180px`），发光呼吸天线（Antenna）、俏皮小弧线嘴，代表智能灵感的 AI 助手。
- **3D 软胶立体质感（Claymorphism）**：
  - 角色由平涂色块升级为顶部亮-底部深微渐变；
  - 叠加受光内高光（`inset 0 4px 8px rgba(255, 255, 255, 0.42)`）与暗部内阴影；
  - 瞳孔内嵌纯白反光微高光点（`pupil-glint`）；
  - 两颊增加柔和半透明腮红，补齐背景舞台氛围光晕（`.character-halo`）与随动作缩放的脚底独立投影。
- **微交互与双向联动**：
  - **双向 Hover 联动**：鼠标悬停在上方能力列表项或小人本体时，对应角色开心向上微弹跳（Bounce），浮现专属问候气泡（`speech-bubble`），列表项同步高亮展开徽标；
  - **表单 Focus 情绪化反馈**：
    - 输入用户名：四个角色按距表单远近差异化倾斜踮脚探头偷看；
    - 输入密码：角色害羞闭眼（`︶ ︶` 细弯弧线）并微退转身“非礼勿视”；
  - **独立视线追踪**：按每个角色在画面的横向锚点独立计算视线注视角度；
  - **高频错峰眨眼**：眨眼周期优化为 `3~6s` 随机错峰。
