# 📂 外部剪藏与三方技术文档归档库 (External-Docs)

本目录用于存放从外部官方文档、技术博客清洗沉淀下来的纯净 Markdown 资料。

## 规约说明：
1. **统一模板**：新建文档请使用 `[[03-Templates/Template-Web-Clipping|Template-Web-Clipping]]` 模板；
2. **清洗原则**：严禁直接粘贴带广告、导航栏的原始 HTML，必须使用纯净 Markdown 格式；
3. **建立连接**：每个外部文档必须在头部显式双链回本知识库的 `[[02-Features/...]]` 或 `[[01-Standards/...]]`，作为工程实现的理论与契约依据。
